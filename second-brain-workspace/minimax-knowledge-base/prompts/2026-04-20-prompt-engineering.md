## 技巧总结

### 高效Prompt结构模板

```
# 角色定义
你是一个[角色]，擅长[领域]

# 任务背景
[描述任务背景和目标]

# 具体要求
1. [要求1]
2. [要求2]
3. [要求3]

# 输出格式
[期望的输出格式]

# 限制条件
[任何特殊限制或注意事项]
```

### 提高稳定性的技巧

1. **明确性**: 使用具体而非模糊的描述
2. **结构化**: 使用列表或XML标签组织
3. **示例**: 提供2-3个典型示例
4. **边界**: 明确说明不做什么
5. **验证**: 要求输出自检或验证

### 常见问题解决方案

| 问题 | 解决方案 |
|------|---------|
| 输出过长 | 指定最大长度或格式 |
| 格式不一致 | 提供输出模板 |
| 幻觉严重 | 要求引用来源/限制范围 |
| 推理跳步 | 使用CoT或分步提示 |
| 角色偏离 | 强化角色定义+示例 |
