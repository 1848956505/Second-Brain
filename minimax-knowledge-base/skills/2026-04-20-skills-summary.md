## 四、高效Skill使用建议

### 1. 学术研究场景

```
# 文献阅读
- 明确阅读目标（快速了解/深度理解/对比分析）
- 提供论文标题和PDF
- 指定输出格式（摘要/关键点/方法/结论）
- 要求标注不确定之处

# 论文写作
- 先让AI理解你的研究贡献
- 提供写作风格参考
- 逐章节迭代优化
- 检查逻辑连贯性
```

### 2. 编程开发场景

```
# 新功能开发
1. 明确需求和验收标准
2. 让AI生成初步实现
3. 测试和反馈
4. 迭代优化

# Bug修复
1. 提供错误信息和上下文
2. 让AI分析可能原因
3. 生成修复方案
4. 验证修复效果
```

### 3. 工具选择建议

| 任务 | 推荐工具 |
|------|---------|
| 文献阅读和总结 | Claude + Papers |
| 代码编写 | Cursor / Claude Code |
| 测试生成 | Cursor / Codium |
| 代码审查 | GitHub Copilot |
| 自动化脚本 | Claude Code |
| 全栈开发 | V0 / Lovable |
